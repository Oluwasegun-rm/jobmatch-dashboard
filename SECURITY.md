Security Policy
===============

Reporting a Vulnerability
- Please do not open public issues for security reports.
- Email the maintainers or use the repository contact (e.g., GitHub security advisories) to disclose privately.
- We aim to respond within 72 hours.

Scope
- Backend FastAPI service and its endpoints
- Frontend application
- CI workflows and Docker configuration

Out of scope
- Third-party providers (Remotive, OpenAI); report incidents to the relevant vendors
